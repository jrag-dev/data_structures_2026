## 📖 Overview | Visión General

Arrays are the most fundamental data structure in computer science. This repository contains **9 essential array operations** with clean, documented implementations.

Los arreglos son la estructura de datos más fundamental en ciencias de la computación. Este repositorio contiene **9 operaciones esenciales con arreglos** con implementaciones limpias y documentadas.

### Key Concepts Covered | Conceptos Clave Cubiertos
- ✅ Array declaration and initialization | Declaración e inicialización
- ✅ Element access with bounds checking | Acceso con verificación de límites
- ✅ Linear and binary search | Búsqueda lineal y binaria
- ✅ Insertion and deletion | Inserción y eliminación
- ✅ Array reversal | Inversión de arreglos
- ✅ Array rotation | Rotación de arreglos
- ✅ Time complexity awareness | Conciencia de complejidad temporal
- ✅ Edge case handling | Manejo de casos límite
